# Reyhaneh Torab Resume

A responsive two-column resume website built with HTML and CSS.

## Overview
This project is a personal resume website created to present my background, technical skills, work experience, and education in a clean and professional format.

## Features
- Two-column resume layout
- Responsive design for smaller screens
- Professional summary section
- Work experience section
- Skills and education sections
- Contact links for GitHub, LinkedIn, and email

## Technologies Used
- HTML5
- CSS3
